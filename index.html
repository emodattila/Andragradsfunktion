Andragradsfunktioner

Typuppgifter från nationella prov, med poäng, lösningsvägar och vanliga fallgropar.

Välj rätt väg

Nollställen → f(x) = 0
Skärning → f(x) = g(x)
Symmetrilinje → x = −p/2
Antal rötter → D = (p/2)² − q
Extremvärde → sätt in x = −p/2 i f(x)
Lodrätt avstånd → |f(x) − g(x)|

Här är p koefficienten i den normaliserade formen x² + px + q; för ax² + bx + c är p = b/a.

Poäng och hjälpmedel

Poäng anges som E/C/A. Exempel: 0/2/1 betyder två C-poäng och en A-poäng i originaluppgiften.

Varje kort visar originalprovets delprov. På B och C används inga digitala verktyg. På D är digitala verktyg tillåtna.
