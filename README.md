# Ma2c – Andragradsfunktioner

Önálló, statikus weboldal. A tartalom, a stílus, a szűrőgombok és a 26 PDF-kivonat helyben található. Nincs szükség szerveroldali futtatókörnyezetre, adatbázisra vagy ChatGPT-fiókra a közzétett másolat működéséhez.

## Megnyitás

Nyisd meg az `index.html` fájlt egy böngészőben. A PDF-ekre mutató hivatkozások a mellette lévő `pdf` mappára mutatnak. A mappa szerkezetét tartsd meg.

## Feltöltés

GitHub Pages vagy más statikus webtárhely esetén az `index.html` és a `pdf` mappa kerüljön ugyanabba a közzétett gyökérmappába. Ha GitHubon a teljes projektmappát helyezed a tároló gyökerébe, a Pages forrását erre a gyökérmappára állítsd; egyébként a kiválasztott közzétételi mappába másold a fájlokat. A hivatkozások relatív útvonalakat használnak, ezért az oldal projektalútvonalon is működik.

## Szerkesztés

A tartalom, a CSS és a JavaScript az `index.html` fájlban van. A `pdf` mappában a nemzeti vizsgák feladatainak és bedömningsanvisningjainak megjelölt kivonatai találhatók. A projekt nem függ a jelenlegi Sites-címtől.
